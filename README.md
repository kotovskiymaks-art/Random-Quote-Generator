Random Quote Generator
Автор: Котовский Максим
Описание
Приложение на Python с графическим интерфейсом (tkinter) для генерации случайных цитат с сохранением истории и фильтрацией.  
Поддерживает добавление новых цитат, фильтрацию по автору и теме, автоматическое сохранение истории в JSON.
Функции
Генерация случайной цитаты из предопределённого списка или добавленных пользователем
История всех сгенерированных цитат с временной меткой
Фильтрация истории по автору или теме
Добавление новых цитат через GUI (с проверкой на пустые строки)
Сохранение цитат и истории в JSON-файлы для сохранения между сеансами
Требования
Python 3.6+
Стандартные библиотеки: `tkinter`, `json`, `random`, `os`, `datetime`
